# FitQuest AI Coach Installation Guide

## Backend Setup

1. **Install Dependencies**
   ```bash
   cd backend
   npm install @google/generative-ai
   ```

2. **Set Up Gemini API Key (Optional)**
   - Follow the guide in `backend/GEMINI_SETUP.md`
   - Or leave it empty to run in fallback mode

3. **Start the Backend**
   ```bash
   npm run dev
   ```

## Frontend Setup

1. **Install Dependencies** (if not already done)
   ```bash
   cd Frontend
   npm install
   ```
